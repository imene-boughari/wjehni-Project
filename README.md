Wejehni — Post-Baccalaureate Orientation Platform
📌 About the Project

Wejehni (وجهني) is a web platform designed to help Algerian Baccalaureate students make more informed decisions about their academic orientation.

The platform provides personalized recommendations based on students' academic results and helps them explore suitable university fields and specialties.

🎯 Problem

Choosing a university field after the Baccalaureate can be challenging for students. Admission requirements, available specialties, and academic results can make the orientation process difficult to navigate.

💡 Solution

Wejehni simplifies the orientation process through an intuitive three-step journey:

Select a desired field or specialty.
Enter the Baccalaureate average.
Provide the required academic grades.

The platform then provides personalized orientation recommendations based on the student's academic results.

✨ Features
🎓 Personalized post-Baccalaureate orientation
📊 Recommendations based on academic results
🔎 Exploration of university fields and specialties
🇩🇿 Adapted to the Algerian education system
📱 Responsive interface for desktop and mobile
🌐 Arabic RTL user interface
⚡ Simple and intuitive three-step user journey
🛠️ Technologies
Frontend: React, JavaScript
Backend: Node.js
Styling: CSS
Database: Database management for specialties and admission requirements

Deployment: Vercel
